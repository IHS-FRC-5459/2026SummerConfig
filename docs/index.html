Typed JSON config for FRC robots

Store robot settings in JSON, publish them to NetworkTables under /Config, tune live in Elastic during debug, and read typed values from robot code. Built by Team 5459 — Ipswich TIGERS.

Ship committed defaults with a normal code deploy. In match mode, NetworkTables is display-only so drivers cannot accidentally overwrite competition values.

Debug vs match (short version)

Mode When Getters NT edits / JSON
Debug Not on FMS, and /Config/DebugMode on Live NT-backed document Edits applied; autosave to config-cache.json; promote with Save
Match FMS attached, or DebugMode off robot-config.json defaults NT publish only; no JSON writes
