Troubleshooting

Start with the Driver Station console — look for lines prefixed with [Config].

Screenshot: Driver Station console with [Config] log lines Placeholder for your capture
Symptom Likely cause / fix
PID / values look like zero Missing path or missing composite field — check warnings and the exact path string. Wrong getter type also returns that getter’s default.
Getter returns zero but JSON looks fine Wrong getter (e.g. getInt on a double). Use the matching typed getter.
Cannot tune from Elastic DebugMode off, or FMS attached (match mode). Only scalar/array leaves are NT-editable.
Tuned values disappear after reboot You only wrote config-cache.json. Press Save, then deploy robot-config.json.
Create/Delete did nothing Not in debug, or Go never pulsed true. Check notifications / console.
Layout / widgets look stale after Create/Delete Elastic does not auto-reload layout JSON — re-import or reopen elastic-layout.json.
Cannot find updated cache in sim Writes go to Filesystem.getDeployDirectory() (often under build/...). Read the absolute path from [Config] Saved config cache:.
Robot crashes on startup loading config Invalid JSON or unknown "type" string — fix the file. This fails loudly on purpose.
Elastic cannot connect to sim Try host 127.0.27.1 as noted in the project README.
