Setup — ConfigManager and robot-config.json

Get the library loading JSON, publishing to NetworkTables, and running every robot loop.

  1. Put the package on your robot project. Copy org.team5459.config (and its Jackson / WPILib dependencies) into your vendor or source tree the same way this repo ships it, or clone this project and start from here.
  2. Add deploy JSON files. Under src/main/deploy/, create at least:
    • robot-config.json — committed defaults
    • config-cache.json — can start as {} or a copy of defaults
    Optional: copy example-layout.json to elastic-layout.json for dashboard controls (see Elastic layout).
  3. Construct ConfigManager in robotInit. 
    @Override
public void robotInit() {
  configManager =
      new ConfigManager(
          new File(Filesystem.getDeployDirectory(), "robot-config.json"),
          new File(Filesystem.getDeployDirectory(), "config-cache.json"));
}
  4. Call periodic every loop. 
    @Override
public void robotPeriodic() {
  if (configManager != null) {
    configManager.periodic();
  }
  CommandScheduler.getInstance().run();
}
    This polls Save / Create / Delete, debug mode transitions, and the layout promote watcher.
  5. Write a tiny typed JSON tree. Every entry needs type and value: 
    {
  "Arm": {
    "type": "folder",
    "value": {
      "kP": { "type": "double", "value": 0.1 }
    }
  }
}
    Deploy and confirm /Config/Arm/kP appears in NetworkTables / Elastic.
